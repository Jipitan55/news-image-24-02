A single 1024×1024 infographic summing up Tuesday 24 November 2026's world news: Nvidia brings back Jensen Huang, two US states sue Musk's firms over Grok, Russian strikes kill 14 in Ukraine's Kyiv region, the COP31 climate talks collapse in Antalya, 24 die in an Indonesia factory fire, and the World Chess Championship opens in Geneva. The image is drawn in code (PIL shapes and DejaVu fonts, `draw.py`) and the Node program (`main.ts`) copies it to the output path, verifying the copy byte-for-byte.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
